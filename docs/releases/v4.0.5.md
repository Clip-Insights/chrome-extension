# Clip Insights 4.0.5

A focused study workspace for YouTube: capture useful moments, ask questions, and keep organized notes.

## Highlights

- Account and upgrade links open **app.clipinsights.org**.
- The panel uses the Clip Insights wordmark with responsive header and logo styling.
- Settings brings together account details, plan usage, reset timing, and logout.
- The packaged font assets include the Inter license.

## Study workflow

Capture timestamped screenshots and write notes beside the video. Generate a transcript summary and key points, or ask questions in the streamed chat. Export notes, screenshots, and generated insights as a PDF. Download it locally or save it to your account and organize it in the web dashboard.

AI requests require sign-in, an available transcript, and allowance under the account's plan. Notes and screenshots are working data in the browser and are subject to a five-day cleanup policy; exported PDFs provide longer-term copies.

## Install

Install [Clip Insights from the Chrome Web Store](https://chromewebstore.google.com/detail/ccgechmifoecebnimnccgahnoklklilj), or use the packaged build attached to this GitHub release:

1. Download and extract `clip-insights-4.0.5.zip`.
2. Open `chrome://extensions` and enable Developer mode.
3. Choose **Load unpacked** and select the extracted folder containing `manifest.json`.
4. Open a YouTube watch page to use the study panel.

The store listing and GitHub package are separate distribution channels; the store can have its own review schedule.

## Technical details

- Extension version: `4.0.5`.
- Manifest version: `3`.
- Supported platform: YouTube.
- Runtime permission: `identity`, for user-initiated Google sign-in.
- Code: React 18, TypeScript, Vite, and CRXJS.
