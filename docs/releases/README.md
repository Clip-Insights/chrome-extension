## Package layout

A release ZIP should contain `manifest.json` at the archive root, together with all assets referenced by that manifest. Source-only archives generated by GitHub are not compiled extension packages.

Build with the intended public configuration, verify the generated manifest version, run the extension tests, and check the packaged extension in Chrome before publishing. Publishing release text does not submit a package to the Chrome Web Store.
