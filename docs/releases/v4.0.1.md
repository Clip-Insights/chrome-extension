# Clip Insights 4.0.1

A maintenance release for Google sign-in configuration.

- Includes the extension OAuth client configuration used by Google sign-in.
- Uses the background service worker to run the interactive Google authentication flow.
- Provides the same video study workflow: screenshots, timestamped notes, summaries, chat, transcript copy, and PDF export.

Account features use the shared Clip Insights backend. AI requests are subject to the signed-in user's plan and transcript availability.
